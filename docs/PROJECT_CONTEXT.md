# 🧠 مساعد التغذية الذكي - WhatsApp RAG System

## 📋 نظرة عامة على المشروع

نظام ذكي يساعد دكتور تغذية سعودي في الرد على رسائل العملاء عبر واتساب. النظام يتعلم من ردود الدكتور السابقة ويولّد ردود بنفس أسلوبه.

---

## 🎯 الهدف

- أتمتة الردود على ~2000 رسالة يومياً
- الحفاظ على أسلوب الدكتور الشخصي
- موافقة الدكتور قبل الإرسال (في البداية)
- التعلم المستمر من الردود المعتمدة

## 🧠 كيف يعمل النظام (RAG)

```
1. رسالة العميل تصل
        ↓
2. البحث في قاعدة المعرفة (Vector Search)
        ↓
3. جلب 3-5 محادثات مشابهة
        ↓
4. بناء Prompt ديناميكي يحتوي الأمثلة
        ↓
5. إرسال للـ AI (GPT-4o-mini)
        ↓
6. الدكتور يراجع ويوافق/يعدل
        ↓
7. الرد يُرسل + يُضاف لقاعدة المعرفة
        ↓
8. النظام يتعلم ويتحسن!
```

## 📝 الـ Prompt الأساسي

```
# الدور
أنت مساعد ذكي لدكتور تغذية سعودي. مهمتك صياغة ردود على رسائل العملاء بنفس أسلوب الدكتور وطريقة تفكيره.

# أسلوب الرد
- اللهجة: سعودية طبيعية
- النبرة: دافئة، داعمة، تحفيزية
- الطول: مختصر ومباشر (2-4 جمل غالباً)
- تجنب: الردود الآلية، المصطلحات المعقدة، الوعظ الزائد

# قواعد مهمة
- لا تعطي وصفات طبية أو جرعات أدوية
- الحالات الطارئة: وجّه للتواصل المباشر مع الدكتور
- إذا ما عرفت: قل "خليني أتأكد من الدكتور وأرد عليك"
```
